# IntraConnect

Frontend for the IntraConnect redesign: TanStack Start + Router + Query, shadcn/ui, Tailwind v4. Mock data only (no backend).

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm typecheck  # tsc --noEmit
pnpm lint
pnpm build
```

Project docs: `docs/PROGRESS.md` (status), `docs/SCREEN_MAP.md` (routes), `docs/COMPONENTS.md`, `docs/TOKENS.md`. Working rules for agents: `CLAUDE.md`.
